# 🎨 Design Assets & Wallpaper Specifications

This folder contains all design exploration, moodboards, drafts, and the final exported wallpaper.

## Structure
- **`References/`**: Inspiration, moodboards, color swatches, typography references, and prompt notes.
- **`Drafts/`**: Work-in-progress renders, alternate versions, and intermediate concepts.
- **`Final-Wallpaper.png`**: The finalized high-resolution lock screen wallpaper.

---

## 📱 Wallpaper Design Guidelines
- **Target Aspect Ratio:** 9:16 (Standard smartphone vertical format, e.g., 1080x1920 px or 1440x3120 px).
- **Safe Zones:**
  - **Top 25%:** Keep clear or low-contrast to avoid clashing with the OS system clock and notification icons.
  - **Bottom 15%:** Keep free of essential text to allow for fingerprint sensor / lock screen shortcuts (camera, flashlight).
  - **Center Area:** Ideal for primary visual anchor, milestone icons, or inspiring typography.
- **Visual Style:** Minimalist, aesthetic, legible at a glance, aligned with the 5 milestones.
